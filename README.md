# BookEasyBot – Telegram Bot for Booking  

## 📌 Project Description  
**BookEasyBot** is a Telegram bot that serves as the frontend for the **BookEasy** SaaS solution. It allows clients to easily book services and interact with professionals.  

## 🔹 Main Features  
✅ Quick and easy service booking.  
✅ Collection and transmission of user data.  
✅ Formatting and displaying information to users.  
✅ Sending notifications and reminders to users.  
✅ Interaction with the backend for processing payments and subscriptions.  

## 🛠️ Tech Stack  
- **Aiogram** – framework for working with the Telegram API.  
- **FastAPI** – server for handling bot requests.
